DocsApp

A pretend document app. Before processing a document, its backend asks the metering service for permission. The client code never changes; only plans do.

Try this

  1. Alice processes a 10-unit document: accepted.
  2. Alice processes a 25-unit document: rejected by her user plan (Basic: 20 per request).
  3. Bob processes 100-unit documents until the team runs out: rejected by the account plan.
  4. Switch Alice to Premium and retry 25: accepted.
  5. Raise the team allowance to 1000 and Bob can continue.
  6. "Send twice" sends the same request id twice: consumed once.
